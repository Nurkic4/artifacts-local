## 01 · 先把重点说清楚

设想我们要整理一次短途旅行：**两天、一座城市、少量行李**。一份实用的计划，应让人快速找到时间安排，也留下足够的自由。

第一天留给城市：上午走进老街，下午看一场展览，傍晚沿河散步。第二天留给自然：清晨出发，午后返回，在回程前留出一小时休息。

> 计划的价值，是减少反复决策，让注意力回到眼前的体验。

这段正文展示中文长段落、**加粗重点**、*轻量强调*和引用的排版。`Markdown` 是一种用简单文本标记表达文档结构的格式。

## 02 · 把安排放进表格

以下为虚构的示例安排，用于查看列对齐和信息密度。

| 时段 | 第一天：城市漫游 | 第二天：亲近自然 |
| :--- | :--- | :--- |
| 09:00—12:00 | 老街早餐与步行 | 公园轻徒步 |
| 12:00—14:00 | 午餐与休息 | 午餐与返回 |

- 带好证件、水杯和充电设备。
- 确认交通时间与场馆开放信息。
- 为临时发现的小店或风景留出空闲。

## 04 · 代码也应容易阅读

语法高亮（用颜色区分代码中的不同元素）帮助读者看清结构。下面的 JavaScript 示例计算两天行程的预算，仅用于演示代码排版。

```javascript
const trip = {
  days: 2,
  dailyFood: 120,
  transport: 180,
  tickets: 100,
};

const total = trip.days * trip.dailyFood
  + trip.transport
  + trip.tickets;

console.log(`预计预算：${total} 元`); // 520 元
```

## 05 · 让数字有清楚的表达

用 $B$ 表示预算，$d$ 表示天数，$f$ 表示每天餐饮费用，$t$ 和 $e$ 分别表示交通与门票费用：

$$
B = d \times f + t + e
  = 2 \times 120 + 180 + 100
  = 520
$$

若额外预留 $15\%$，则总预算为：

$$
B_{\text{总计}} = B \times (1 + 15\%) = 598\text{ 元}
$$
