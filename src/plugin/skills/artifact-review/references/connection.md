# 展示排查

只在展示失败时读取。默认入口只生成本地文件；SSH、Tailscale 和 `.codex/artifacts.json` 均不参与。

- 工具未发现：核对宿主是否加载插件的 `mcp.json`；程序使用 Node.js，经标准输入输出通信，不开放网页端口。不同宿主的配置路径可能不同。工具不可用时使用命令行入口。
- 生成失败：核对项目绝对路径、源文件及 assets 是否存在并在工作区内；保留实际错误，不返回空白页。
- 页面加载失败：核对 `.artifacts/runtime` 及页面资源是否存在，尝试重新生成。宿主禁止本地文件时，只报告该宿主限制，不推导为所有编辑器都不支持。
- 看到旧内容：阅读页是生成时的快照；修改后再次调用工具并刷新。不会后台监视文件。
- 看到 HTML 源码：页面被源文件编辑器打开了，改用浏览器打开返回的 `url` 或 `openTarget`。这不是渲染器故障，不需要重新构建或启动服务。
- 中文文档链接：把目标 Markdown 放入 assets。未包含的文档应由 Agent 重新生成时提供，页面不会自行读取整个项目。
