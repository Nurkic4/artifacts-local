# 开发与本地资源

本仓库只包含自主编写的适配代码、技能、测试和示例，不包含 Antigravity 原版前端资源。当前适配依赖 Antigravity 2.19.1 的内部组件，其他版本不能保证兼容。它还不是独立、完全开源的 Markdown 解析器。

## 准备

需要 Node.js 22 或更新版本。执行 `npm ci` 安装依赖。

原版资源必须由使用者在合法授权范围内自行准备。导入命令接收已经提取的资源目录，不接收 Antigravity 安装目录，不自动下载或绕过访问限制。目录须包含：

- `main.js`、`prism_bundle.js`、`jetbox.css`、`compiled_tailwind.css`、`theme.css`。
- `katex.min.css` 以及 `fonts/`，字体路径须与样式相符。
- `workers/`，其中包含 `pdfjs_loader.mjs`、`pdf.min.mjs`、`pdf.worker.mjs`。
- `index.html`：本地验证用页面外壳，含文档主题变量及 `<header` 分界。构建只取该分界前的 HTML 外壳，再插入项目自己的页面入口；不要使用含账户、凭据或联网初始化的完整应用页面。

```text
node scripts/import-renderer.cjs <已提取资源目录的绝对路径>
npm run build
npm test
node src/present.cjs <项目绝对路径> samples/阅读体验演示.md samples/reading-journey.svg
```

资源导入 `research/original-viewer`，构建输出 `dist`；两者均不进入 Git。没有资源时可以先运行 `node --test tests/core.test.cjs` 检查存储模块。完整展示和相关测试需要先构建。仓库不包含一键提取任意 Antigravity 安装版本的实现。

## Agent 接入

支持 MCP（模型调用工具的协议）的宿主可将命令配置为 `node`，参数设为本仓库 `src/mcp.cjs` 的绝对路径。先完成资源导入与构建。将 `src/plugin/skills/artifact-review` 作为技能导入；具体技能安装方法取决于宿主。默认只有 `artifacts_present` 一个工具。

```json
{
  "mcpServers": {
    "artifacts": {
      "command": "node",
      "args": ["<仓库绝对路径>/src/mcp.cjs"]
    }
  }
}
```

这里的占位路径应由使用者填入，不能直接复制运行。普通编辑器扩展构建保留在 `npm run package` 中，只用于使用者自己的本地研究，含原版资源的生成包不得随源码发布。VS Code 集成测试可设置 `VSCODE_EXECUTABLE_PATH` 指向其可执行文件；未设置时测试工具下载测试用编辑器。

## 数据与迁移

默认入口把内容写入工作区 `.artifacts/pages`，并把本地渲染资源缓存在 `.artifacts/runtime`。不会上传文档，不需要服务器或常驻网页服务。阅读快照包含文档内容，不能作为无敏感数据的文件随意发布。源文件修改后，Agent 再次调用展示入口生成新快照。

`src/server.cjs`、`src/remote.cjs` 等是保留的旧实验入口，不是默认工作流。历史服务端文档、个人配置和实验记录未纳入仓库。跨编辑器协议接入不等于所有宿主都允许显示本地 HTML；被宿主禁止时，应报告限制并提供源文件。
